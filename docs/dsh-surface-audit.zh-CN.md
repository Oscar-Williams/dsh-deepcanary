# DSH 公开接口

[English](dsh-surface-audit.md) · [架构](architecture.zh-CN.md)

插件接入 DSH 0.2.2-alpha.3 和 0.2.1-rc.5，覆盖 WebUI 与 Windows 桌面版。契约测试通过 `DSH_RUNTIME` 选择实际安装的运行时。

| 接口 | DeepCanary 用途 |
| --- | --- |
| 会话存储与生命周期 | 读取快照、序列边界、轮次结果及保留的会话身份 |
| 问答与审批投影 | 跟踪每个人工事项及其权威结束状态 |
| Job Registry | 观察原生归属、生命周期、输出计数和结束状态 |
| Agent 与子任务事件 | 关联父子关系和执行失败 |
| 自动化 | 关联调度发生项、投递、目标会话及已接收执行 |
| Settings 与 ConfigForm | 读取配置，按预期 revision 提交事务 |
| Connection Fetch | 注册鉴权路由，限制请求体并随所有者释放 |
| 会话导航 | 核验当前目录中的目标并打开对应会话 |
| UI 扩展槽位 | 注册收件箱、侧边栏入口和设置 |
| alpha.3 上下文菜单与图标 | 注册鼠标与键盘菜单、设置导航图标 |
| Cordis effects | 释放注册项并等待尚未完成的状态写入 |

RC5 通过公开扩展槽位提供对应操作。alpha.3 可选服务按能力加载，随所有者释放。

## 通信

`/api/dsh-deepcanary/` 路由使用宿主鉴权的 Connection Fetch 注册表。写请求体上限为 32,000 字节。客户端使用相对地址、请求身份、revision 检查和通知代次。

桌面版通过 `dsh-app://app` 来源转发相同路径。通知与导航使用公开渲染进程能力。完全退出桌面应用会停止宿主和渲染进程。

## 更新接入

检查插件所用公开接口的变化，在新运行时中执行受影响的契约测试，并在应用内检查改变的行为。完成这些检查后才扩大已测试范围。源码固定版本和已测试桌面构建见 [兼容性](compatibility.zh-CN.md)。
