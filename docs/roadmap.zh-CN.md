# 路线图

[English](roadmap.md)

DeepCanary 帮助用户让任务持续运行，在需要输入时及时处理，并返回对应工作。

## 0.1.8 已实现

- 同一个包和界面支持 DSH alpha.3、RC5 的 WebUI 与 Windows 桌面版。
- 待处理、稍后、动态视图；可拖动和缩放的面板；列表与详情导航；键盘控制；设备本地布局。
- 独立的问答、审批、执行、Job、子任务和自动化身份。
- 状态迁移、重启恢复、并发操作保护和持久化通知认领。
- 在持续运行的 Web 与桌面宿主中提供原生通知与会话回跳。

## 后续方向

| 目标 | 实施依据 |
| --- | --- |
| 跟进 DSH 更新 | 已发布更新影响插件时，检查变化的公开契约 |
| 提高提醒准确性 | 复现遗漏、误报、迟到或重复提醒，补定向回归并修复 |
| 完善长任务支持 | 后台或子任务暴露缺失生命周期时，扩展状态核对 |
| 改善收件箱 | 解决查找、阅读、改期和返回工作中的实际困难 |
| 支持更多平台 | 在对应应用中完成安装、通知、导航和输入测试 |
| 调整提醒策略 | 在不同任务和工作日中比较打断与有效提醒 |

注意力判断和 C3 权威条件由确定性核心负责。新增事实来源应保留任务归属、隐私、容量约束和正常工作时的安静行为。

已交付变化见[更新记录](../CHANGELOG.zh-CN.md)，实施方法见[开发指南](development.zh-CN.md)。
