# Screenshot details

[简体中文](ui-captures.zh-CN.md)

The English and Chinese README images show the running DeepCanary 0.1.8-rc.1 client in DSH 0.2.2-alpha.3, captured on 4 November 2026 (Asia/Shanghai). Later 0.1.8 candidates retain this interface.

The samples use public DSH services in an isolated profile: a timed question, a background Node job that exits with code 1, and a completed session. They contain controlled sample content. Session titles are resolved for display from DSH and stay outside the reminder ledger.

Playwright captured the implemented panel directly. The dark appearance follows the host theme. The images are stored in `assets/deepcanary-panel-en.png` and `assets/deepcanary-panel-zh.png`; `screenshots.json` provides their catalog metadata.
