# 兼容性

[English](compatibility.md) · [安装](../README.zh-CN.md#安装)

DeepCanary 0.1.8 在以下宿主中使用同一个包和界面。

| DSH 版本 | WebUI | Windows 桌面版 | WebUI 的 Node.js 要求 |
| --- | --- | --- | --- |
| 0.2.1-rc.5 | 已测试 | 已测试官方应用 | ^22.19.0 或 >=24.0.0 |
| 0.2.2-alpha.3 | 已测试 | 已测试固定源码构建 | >=24.9.0 |

包声明为 `engines.dsh = "0.2.1-rc.5 || >=0.2.2-alpha.3"`。后续版本可以直接安装，无需修改版本白名单；完成实际宿主检查后才会列入已测试范围。更早的 DSH 版本不在支持范围内。

alpha.3 桌面测试使用未签名的本地构建，源码提交为 `05b1cae8db6e674c5685101494d4eec24652424a`。已测试的官方 RC5 桌面版报告提交为 `d4db512a969fccf0c5cc7ec8fe38e9c1d27af916`；RC5 源码标签指向 `b830ec950faba0a46dda564be3e2d854afed94f1`。

## 界面

两个版本均提供待处理、稍后、动态、提醒设置、会话跳转和面板控制。alpha.3 使用统一上下文菜单和设置图标接口，RC5 通过公开会话槽位与收件箱菜单提供对应操作。

布局检查覆盖浅色与深色主题、窄窗口、键盘、模拟触控和 Edge 实际 200% 页面缩放。尚未测试实体触屏设备及其他操作系统。

## 通知

Web 通知需要授予 DSH 站点权限，并保持页面运行。桌面通知需要应用持续运行。Windows 测试覆盖桌面窗口最小化、隐藏、系统横幅及返回对应提醒。

完全退出桌面应用会停止宿主与渲染进程。浏览器权限、Windows 勿扰、静默时段和提醒预算均会影响通知显示。

## 宿主更新

可选服务按能力加载。插件使用 DSH 公开服务，停用或卸载时释放注册项。具体接入方式见 [DSH 公开接口](dsh-surface-audit.zh-CN.md)。

DSH 更新涉及插件所用接口时，运行受影响的契约测试，并在应用中检查对应行为，然后再扩大已测试范围。
