# 仓库目录

[English](workspace-layout.md) · [开发说明](development.zh-CN.md)

## 源码与分发

| 目录 | 内容 |
| --- | --- |
| `src/` | 插件服务、Provider、策略、持久化及客户端源码 |
| `test/` | 回归测试和受控样本 |
| `scripts/` | 构建、宿主契约、打包和维护命令 |
| `lib/` | 与源码一并提交的生成分发文件 |
| `assets/` | 公开界面截图 |
| `docs/` | 用户与贡献者文档 |
| `benchmark/` | 开发工具使用的回归输入和结构定义 |
| `output/` | Git 忽略的构建结果、候选包和本地报告 |

测试时使用单独的 DSH 数据目录，其中的配置、凭据和提醒状态与日常使用分开。

## 版本

开发宿主为 DSH 0.2.2-alpha.3，兼容宿主为 RC5。固定源码提交与实际桌面构建身份见[兼容性说明](compatibility.zh-CN.md)。

本仓库使用 npm 与 `package-lock.json`，宿主 profile 使用其自带的包管理器，宿主服务从自身安装中解析。

## 分发包

在 `lib/` 已同步后冻结审阅过的提交，输出到 `output/releases/<version>/`。本地清单关联源码提交、包内容和校验值。

文件比较确认安装内容，冷启动确认实际加载版本，行为变化通过真实应用验证。

生成的回执、本机路径、认证链接及私密样本保留在本地输出中，Release 附件包含分发包及其校验值。
