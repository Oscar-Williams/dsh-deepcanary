# 数据与隐私

[English](security.md) · [安全政策](../SECURITY.zh-CN.md) · [文档目录](README.zh-CN.md)

## 保存的数据

DeepCanary 在所选 DSH profile 中保存提醒元数据，包括用于返回会话的标识、哈希关联、原因码、任务与提醒状态、稍后时间、预算和有界通知记录。

会话标题由运行中的宿主提供显示。会话正文、提示词、答案、工具参数、模型输出、凭据和原始失败文本不进入提醒账本。工具失败只提取工具名称、安全错误分类或退出码。

请将 profile 数据视为私密资料。即使没有会话正文，元数据和标识也可能反映工作情况。

## 本地判定与动作

提醒使用确定性的本地规则判定，C3 必须来自当前有效的权威问答或审批。主动取消的任务通过公开结果枚举识别。

插件动作包括将提醒标记为已处理、稍后、静音、补充反馈及返回 DSH。任务执行、问题回答和审批决定使用 DSH 原生流程。

## 认证与并发

`/api/dsh-deepcanary/` 路由使用 DSH 经过认证的 Connection Fetch 注册接口，写入请求有大小限制。协议 3 检查请求标识、revision 和执行代次；通知回调还检查对应的通知代次。

每个账本由一个宿主写入，连接该宿主的页面共享状态，不同 profile 分别保存账本。

## 持久化与迁移

存储以原子方式写入 schema 2，保留稍后安排、预算和通知认领，并迁移已有合法数据。损坏或不支持的数据会保留，激活时明确报告错误。

通知认领保存成功后才允许构造通知。保存失败时暂停授权，并提供重试入口。

## 通知

通知正文使用本地化摘要，具体显示位置由 Windows 和浏览器权限控制。按系统设置，横幅可能显示在 DSH 窗口之外，甚至锁屏上。

构造、送达、可见和点击分别记录。通知送达不会完成原生任务。

漏洞通过[安全政策](../SECURITY.zh-CN.md)中的私密渠道报告。普通报告只附复现问题所必需的信息。
