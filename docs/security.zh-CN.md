## 数据保存在哪里

DeepCanary 默认将数据保存在 DSH 数据目录下的 `profiles/<profile>/state/deepcanary/`。DSH 数据目录默认为 `~/.dsh`。设置了 `DSH_HOME` 时，请在该目录中查找。

- `inbox.json` 保存提醒状态与时间、用于跳转的会话标识、任务引用、稍后提醒的计划、通知额度及近期投递记录。
- `suppressions.json` 保存你已静音的提醒类型。
- `outcomes.json` 保存对提醒的反馈，以及对应任务是否已恢复。
- 显示提醒时，DeepCanary 从 DSH 读取当前会话标题。收件箱文件中不保存标题、对话正文、提示词、答案、工具参数、模型输出、凭据和原始报错。

请妥善保护 DSH 数据目录。会话标识和时间也可能反映你的工作情况。

## 访问与写入

收件箱向当前 DSH 站点发出请求。DSH 先检查来源和认证状态，再将请求交给 `/api/dsh-deepcanary/`。DeepCanary 将 JSON 写入请求限制在 32,000 字节，并在更新前核对提醒是否仍与页面上显示的状态一致。

不同配置各自保存提醒文件。多个页面连接同一个 DSH 实例时，共享该实例的提醒状态。DeepCanary 每次请求系统发送提醒前，都会先保存本次投递记录。重启后，它根据这些记录避免重复提醒。

保存失败时，先检查运行 DSH 的账户能否写入配置目录，再点击收件箱中的**刷新状态**。在恢复写入之前，DeepCanary 会暂停发送系统提醒。

## 通知

系统横幅显示本地化摘要。根据浏览器和操作系统设置，横幅可能出现在 DSH 之外或锁屏上。处理敏感任务时，可以在系统中调整通知预览。

请通过私密表单报告漏洞。参见[安全政策](../SECURITY.zh-CN.md)。
