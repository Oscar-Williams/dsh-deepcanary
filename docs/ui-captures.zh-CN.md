# 截图说明

[English](ui-captures.md)

中英文 README 展示的是在 DSH 0.2.2-alpha.3 中运行的 DeepCanary 0.1.8-rc.1 客户端，截图时间为 2026 年 11 月 4 日（Asia/Shanghai）。后续 0.1.8 候选版本沿用这一界面。

示例在隔离 profile 中通过 DSH 公开服务生成：一个限时提问、一个以退出码 1 结束的后台 Node 任务和一个已完成会话。画面使用受控示例内容。会话标题在显示时从 DSH 解析，不进入提醒账本。

截图由 Playwright 直接捕获已实现的面板，深色外观跟随宿主主题。图片位于 `assets/deepcanary-panel-en.png` 和 `assets/deepcanary-panel-zh.png`，目录元数据位于 `screenshots.json`。
